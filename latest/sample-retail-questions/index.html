Sample Retail Questions — Data Agent & Ontology MCP¶

▶ For the live demo, use cio-demo-flow.md — an empirically validated, ordered walkthrough (Numbers → Connections → Live events → Action) with the exact question phrasings, the surface that answers each, and the real numbers seen on 2026-06-26. This catalog below is the broader aspirational set; some multi-hop ontology questions in it are known to fail (see the validated phrasing rules in cio-demo-flow.md): on the ontology avoid receipt_created sales-velocity, cross-entity traversal over events, store N entity-name resolution, and open-ended 360 views; prefer event counts grouped by the owning key (store_id/dc_id), named-customer enrichment, and ML-prediction-as- relationship. Sales velocity belongs to the Data Agent ("last 15 min") or KQL.

Business questions to evaluate a Fabric Data Agent (over the retail_model semantic model) and the Ontology MCP (over the retail ontology graph) for the data generated by this deployment.

Use Case Summary¶

This demo deploys a complete Microsoft Fabric Real-Time Intelligence solution for a synthetic omnichannel general-merchandise + grocery retailer, then puts a natural-language conversational analytics layer on top of it. The goal is to let business users — store ops, merchants, supply-chain planners, marketers, and executives — ask questions in plain language and get grounded answers, without writing SQL, KQL, or DAX.

Two complementary AI surfaces sit over the same governed data:

  • Fabric Data Agent over the semantic model — answers metric, trend, and ranked-list questions using ~120 curated DAX measures (net sales, gross profit, omnichannel revenue, inventory-to-sales ratio, tender mix, truck dwell, reorder fill gap, etc.) across the historical (Lakehouse Gold) and near-real-time layers. This is the "what are my numbers" surface.
  • Ontology MCP in VS Code — answers relationship and multi-hop questions by traversing the retail knowledge graph (Store, Customer, Product, Receipt, OnlineOrder, Promotion, Payment, Geography, DistributionCenter, Truck, CustomerSegment, ChurnPrediction). This is the "how is everything connected" surface, and it also reaches the ML outputs.

Underneath, the deployment provides four data surfaces these agents draw on:

Surface Source Example content
🟢 Historical Lakehouse Silver/Gold via the semantic model Sales, margin, omnichannel, inventory, logistics, traffic, marketing
🟠 Real-time Eventhouse KQL event tables + materialized views Per-minute sales velocity, 15-min top products, live zone dwell, tender mix, anomalies
🔷 Relationships Retail ontology graph (12 entities) Customer→Receipt→Product, Store←Truck←DC, Promotion→Customer
🧠 Predictive (ML) ML Gold tables Churn, RFM segmentation, demand forecast, stockout risk, market basket, price elasticity, dynamic pricing, journeys, delivery dwell

Business value demonstrated: retention (churn + segmentation), revenue protection (stockout risk vs forecast vs replenishment), margin optimization (elasticity-aware pricing and promo effectiveness), omnichannel growth (fulfillment mix), and real-time store operations — all reachable through one conversational experience over governed Fabric data.

How to use this document: Run the single-surface questions (sections 1–15) first to validate each capability in isolation, then run the cross-surface set (section 16) to demonstrate the full, executive-grade story.

Calibrate time windows to your deployed data. Replace "last 30 days / this quarter / yesterday" with the actual date range present in your workspace before running.

Legend — which surface should answer it: - 🟢 DA = Data Agent / semantic model (curated DAX measures + dims) - 🔷 ONT = Ontology MCP (entity relationships, multi-hop graph traversal) - 🟠 RT = Real-time (Eventhouse KQL event tables / materialized views) - 🧠 ML = Predictive / ML Gold tables

1. Executive & Sales Performance 🟢 DA¶

  1. What were total net sales, gross profit, and gross margin % company-wide last quarter, and how did that compare to the prior quarter?
  2. Show net sales and units by Region for the trailing 30 days, ranked, with each region's share of total.
  3. Which top 10 stores drove the most net sales last month, and how does each compare to the same month last year (YoY %)?
  4. Break down sales by store volume class (flagship, high_volume, standard, low_volume, kiosk) — which class delivers the highest sales per store and the highest average basket?
  5. What is total omnichannel revenue (in-store + online), and what % of revenue is now digital? How has that channel mix shifted vs last year?
  6. Show month-over-month net sales trend for the last 6 months with the largest single-month swing called out.
  7. What are sales per customer and units per receipt company-wide, and which region over-indexes on basket size?
  8. Which product Departments are this period's biggest gainers and biggest drainers versus last year?

2. Merchandising & Product 🟢 DA / 🔷 ONT¶

  1. What are the top 15 products by revenue last month, and what is each product's gross margin %? 🟢
  2. For the Electronics department, show revenue and units by Category and Subcategory, drilling from Department → Category → Subcategory. 🟢
  3. Which products have the highest return volume, and is the return concentration spread across stores or concentrated in a few? 🟢
  4. Using the graph, list the distinct products a specific high-value customer has ever purchased, across both in-store receipts and online orders. 🔷
  5. Through the ontology, find which stores sold a given product and the customers who bought it — show the Store → Receipt → Product → Customer path. 🔷
  6. Which products carry the highest MSRP-to-cost spread but the lowest sell-through? 🟢

3. Omnichannel & Fulfillment 🟢 DA¶

  1. Compare average order value and units per order between in-store and online channels for the last 30 days.
  2. How is the fulfillment mix trending (Ship-from-DC vs Ship-from-Store vs BOPIS) month over month, and which mode is growing fastest?
  3. Which stores are absorbing the most Ship-from-Store and BOPIS volume, and is that concentrated in specific regions?
  4. What is online revenue year-to-date vs prior year, and what is the digital share of total omnichannel revenue?
  5. What is the payment tender mix (by method) and how does declined-payment rate vary by channel?

4. Inventory, Replenishment & Supply Chain 🟢 DA / 🔷 ONT¶

  1. What is current total units on hand across stores vs DCs, and the network inventory-to-sales ratio?
  2. Which stores have the most open high-priority reorders right now, and what is the total reorder fill gap?
  3. Rank DCs by units on hand and SKU count; which DC is carrying the most inventory relative to the stores it serves? 🔷
  4. Through the graph, trace the replenishment path for a flagged store: which DC and which trucks service it (Store ← Truck ← DistributionCenter)? 🔷
  5. What is average truck dwell time, and how many truck-dwell breach days occurred last month by site?
  6. Which stores show the highest stockout event counts, and does that correlate with their reorder fill gap?

5. Stores, Traffic & In-Store Experience 🟢 DA / 🟠 RT¶

  1. Which stores have the highest foot traffic but the lowest conversion (receipts per visitor) last week? 🟢
  2. What is average customer dwell time by store zone (Entrance, Electronics, Grocery, Clothing, Checkout), and where do customers linger longest? 🟢
  3. Show right-now sales velocity (sales per minute) by store for the current hour. 🟠
  4. What were the top-selling products in the last 15 minutes across the fleet? 🟠
  5. Which checkout zones are seeing the longest dwell in the last few minutes (possible queue build-up)? 🟠

6. Marketing & Promotions 🟢 DA / 🔷 ONT¶

  1. What is total marketing spend and impressions by campaign last month, and the resulting CPM?
  2. Which promotions drove the most discount dollars, and how many receipts did each touch? 🟢
  3. For a specific promo code, use the graph to find which stores ran it and which customers redeemed it (Promotion → Store / Promotion → Customer). 🔷
  4. What is the promo discount as a % of gross sales, and which Department leaks the most margin to promotions?

7. Customer Segmentation (RFM) 🧠 ML¶

  1. How many customers fall into each segment (Champions, Loyal Customers, Potential Loyalists, New Customers, At Risk, Hibernating, Lost), and what is each segment's average lifetime value?
  2. What share of total monetary value is concentrated in Champions + Loyal Customers, and how many customers does that represent?
  3. Which segment has the worst recency, and what is its average frequency and average order value — i.e., where is the biggest win-back opportunity?
  4. Compare average order value across segments — are Champions actually spending more per order, or just more often?

8. Churn Prediction 🧠 ML / 🔷 ONT¶

  1. How many customers are predicted to churn, what is the predicted churn rate %, and what is the average churn probability across the base?
  2. List the high-risk customers (Risk Category = High) with the largest historical monetary value — i.e., the most valuable accounts most likely to leave.
  3. How well is the churn model performing — compare predicted churn against actual churned customers (precision/recall sense-check).
  4. Using the graph, take the top churn-risk customers and surface their RFM segment and recent purchase history so we can prioritize retention offers (Customer → ChurnPrediction + Customer → Segment). 🔷
  5. Which region or store has the highest concentration of high-risk, high-value customers?

9. Demand Forecasting 🧠 ML¶

  1. What are total forecasted units for the next horizon by store, and which stores have the widest confidence interval (most uncertain demand)?
  2. Which product/store combinations have the highest forecast MAPE — i.e., where should we least trust the forecast?
  3. For a given high-volume store, show forecasted units vs lower/upper bound for its top products.
  4. Where does forecasted demand most exceed current on-hand inventory — flag pre-emptive replenishment needs.

10. Stockout Risk 🧠 ML / 🔷 ONT¶

  1. Which store/product positions are at high stockout risk, ranked by stockout probability, and how many days of inventory remain?
  2. How many SKUs are flagged high-risk, and what is the average days-of-inventory and daily demand velocity across them?
  3. Cross the stockout-risk model with open reorders: are high-risk SKUs actually covered by a pending reorder, or are we about to stock out blind? 🔷
  4. For the highest-velocity products, which stores have the thinnest cover (lowest days of inventory)?

11. Market Basket / Recommendations 🧠 ML¶

  1. What are the strongest "bought together" product pairs by lift and confidence — what should we cross-merchandise or bundle?
  2. For a given anchor product, what are the top recommended add-on products and the confidence of each association?
  3. Which high-lift product associations cross Department boundaries (e.g., a grocery item pulling an electronics accessory)?

12. Price Elasticity & Dynamic Pricing 🧠 ML¶

  1. Which products are Highly Elastic vs Inelastic, and what does that imply for where price increases are safe vs risky?
  2. Show the dynamic-pricing recommendations with the largest gap between current price and elasticity-optimal price, with the model's confidence on each.
  3. For elastic products, what revenue lift does the recommended price imply, and which constraints are binding?
  4. Which Categories are most price-sensitive overall — where should promo dollars work hardest?

13. Customer Journey & Behavior 🧠 ML / 🟠 RT¶

  1. What are the most common in-store zone-transition paths, and where do journeys most often end without reaching Checkout (drop-off)?
  2. Which zones act as the biggest "magnets" (highest dwell) versus the biggest drop-off points in the customer journey?
  3. In real time, which customers (by BLE id) have moved through 3+ zones in the current session without a purchase yet? 🟠

14. Delivery / Logistics Prediction 🧠 ML¶

  1. What is the predicted truck-unload dwell time for upcoming deliveries, with prediction intervals — which sites are at risk of long dwell?
  2. Which lanes or sites consistently exceed predicted dwell, suggesting a structural bottleneck?

15. Real-Time Anomaly Detection 🟠 RT¶

  1. Are there any sales or inventory anomalies detected in the last hour (sudden velocity spikes/drops)?
  2. Which stores are showing abnormal stockout-detection or reorder-trigger rates right now versus their normal baseline?

16. "Wow the CIO" — Cross-Surface, Multi-Hop Questions¶

These combine semantic model + ontology + ML and best showcase the platform.

  1. Retention play: Identify Champions and Loyal customers who are also flagged high churn risk, list their favorite Departments, and recommend which products to put in a win-back offer (Segment + ChurnPrediction + purchase graph + market-basket). 🔷🧠
  2. Revenue-at-risk: Quantify the total historical revenue tied to high-churn-risk customers — i.e., dollars on the table if we do nothing. 🟢🧠
  3. Stockout → sales impact: For products at high stockout risk in high-traffic stores, estimate the at-risk daily sales using forecasted demand velocity. 🧠
  4. Pricing + elasticity + margin: For the top 10 margin-leaking promoted products, cross-reference price elasticity — were we discounting inelastic products that didn't need it? 🟢🧠
  5. Demand vs supply gap: Where does next-period forecasted demand exceed combined store + DC on-hand, and is a truck already scheduled to that store? 🧠🔷
  6. Journey → conversion: Combine zone-dwell journeys with conversion by store — do stores with longer Checkout dwell have measurably lower conversion? 🧠🟢
  7. Best next action per store: For each underperforming store (sales below regional median), surface its top stockout risk, top churn-risk customers, and top recommended cross-sell — a single prioritized action list. 🟢🔷🧠

Notes for the tester¶

  • The Ontology MCP is best for relationship / "who-is-connected-to-what" questions and multi-hop traversal; the Data Agent is best for aggregate metrics, trends, and ranked lists backed by curated DAX measures.
  • ML questions (sections 7–14, 16) read the predictive Gold tables (churn_predictions, customer_segments, demand_forecast, stockout_risk, product_recommendations, price_elasticity, pricing_recommendations, journey_patterns, dwell_predictions). Confirm those notebooks have run and the tables are populated/bound before testing.
  • Real-time (🟠) questions require the streaming notebook to be running so the Eventhouse event tables and materialized views have fresh data.
  • Start with single-surface questions (1–65) to validate each capability, then run the cross-surface set (66–72) to demonstrate the full story.
